# Iconos PWA

Esta carpeta debe contener los siguientes iconos para la PWA:

- `icon-192x192.png` - Icono de 192x192 píxeles
- `icon-512x512.png` - Icono de 512x512 píxeles

Los iconos deben ser PNG con fondo transparente o con el color de fondo de la app (#F5F5DC).

Puedes generar estos iconos usando herramientas como:
- [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
